# 猫の集会

猫を迎えてお世話し、ほかの参加者の猫と交流できるペット育成アプリです。Delta Chatのミニアプリ（webxdc）として使うほか、HTMLファイルをブラウザで直接開いて遊べます。

**最新版：1.1.1** · README更新日：2026年10月18日

## はじめに

### ブラウザで遊ぶ

1. [index.html](index.html)をダウンロードします。
2. 保存したファイルをブラウザで開きます。ほかのファイルの用意やサーバーの起動は不要です。
3. 画面上の「ブラウザ版」を確認し、「＋ 新しい猫」から猫を迎えます。

猫と履歴は、このブラウザの保存領域に記録されます。同じファイルを同じブラウザで開き直すと続きから遊べます。**別端末・別ブラウザとは自動で共有されません。**

ファイルの移動や名前の変更、ブラウザの保存データの削除によって、以前のデータを読み出せなくなる場合があります。先に「引き継ぎ」からバックアップを保存してください。データ保存が禁止されている環境では起動できません。

### Delta Chatでみんなと遊ぶ

1. [nekoshu-1.1.1.xdc](nekoshu-1.1.1.xdc)を、遊びたい相手とのチャットまたはグループにファイルとして送ります。
2. 全員が、**その同じアプリのメッセージ**から起動します。
3. 画面上の「Delta Chat版」を確認し、それぞれ猫を迎えます。
4. 相手の猫が表示されたら、お世話や集会を楽しめます。

各自が別々に送り直したアプリや、旧版のアプリを開いても、同じゲームには参加できません。更新の反映には、Delta Chatの送受信状況によって時間がかかることがあります。

## 主な操作

| 操作 | できること |
| --- | --- |
| ＋ 新しい猫 | 名前・毛色・性格を選んで迎える。1人3匹まで |
| 猫の一覧 | お世話する猫を選ぶ。自分の猫は「うちの子」と表示 |
| ごはん | お腹と元気を回復する。お腹が85を超えると使えない |
| なでなで | ごきげんやなつきを上げる |
| ブラッシング | 自分の猫のキレイとなつきを上げる |
| あそぶ | ごきげんを上げる。元気を消費する |
| おうちへ／集会へ | 自分の猫を休ませる／広場へ戻す |
| 手紙 | ほかの人の猫へ手紙やお届け物を送る |
| 郵便受け | 自分の猫に届いた手紙・お届け物を読む |
| 集会 | 議題を選び、広場にいる猫を集める |
| 引き継ぎ | バックアップの書き出し・読み込み |

状態の数値は0～100です。「お腹」は大きいほど満腹を表します。元気はおうちで時間とともに回復します。

集会の参加対象は、開始時点で広場にいる猫です。参加すると、ごきげん・なつき・経験値が増えます。次の集会までは前の開始から約5分待ちます。「集会へ」は猫を広場へ戻す操作で、集会の開催は画面上の「集会」から行います。

## バックアップとバージョン間の引き継ぎ

### 保存する

1. 今使っているアプリの「引き継ぎ」を開きます。
2. 「書き出す」を押します。
3. ブラウザ版ではJSONファイルを保存します。Delta Chat版では、JSONが添付された送信画面で実際に送信して残します。

グループ全体を保存する場合は、相手の猫や直近の操作が反映されてから書き出してください。その端末で受信していない記録は含まれません。

### 新しい版や別のブラウザへ読み込む

1. 引き継ぎ先を開きます。Delta Chatでは全員が同じ新版のメッセージを開いてください。
2. 「引き継ぎ」→「バックアップを選ぶ」でJSONを選びます。
3. 「以前の自分の猫」で自分の猫の名前を確認して選びます。
4. 「この内容で引き継ぐ」を押し、完了まで開いたまま待ちます。
5. 一覧の「うちの子」、レベル、手紙、集会の記録を確認します。

Delta Chatでは、ほかの参加者も同じ新版でバックアップを読み込み、自分の猫を選んで引き継ぎます。表示名だけで持ち主を自動判定しないため、この確認が必要です。「今回は記録だけ読み込む」を選ぶと、持ち主は切り替えません。

同じ記録は重複せず、すでにある新しいお世話も削除しません。履歴が多い場合は分割して処理します。途中で閉じた場合は同じファイルでやり直せます。自分の猫が3匹を超える引き継ぎはできないため、**猫を引き継ぐ前に新しい猫を迎えないでください。**

旧版と新版、ブラウザ版とDelta Chat版は、その後の操作を自動で同期しません。引き継ぎが終わったら、使うアプリをそろえてください。

### 保存対象と上限

- 猫、名前、毛色、性格、経験値、お世話、居場所、手紙、集会の履歴を保存します。
- 未読の印や猫の歩く位置は引き継ぎません。
- 状態は元の時刻から再計算するため、バックアップ中も時間が進みます。
- バックアップ形式は1、ファイルは2MBまで、記録は2万件までです。
- 手紙の本文も含まれます。Delta Chatで読み込むと、そのアプリの参加者に共有されます。

### 1.0.0・1.0.1からの初回移行

旧版には書き出しボタンがありません。[旧版から初めて引き継ぐ方へ](旧版から初めて引き継ぐ方へ.txt)と[取り出し補助スクリプト](旧版データ取り出し.js)を用意しています。

元の猫が見える旧版のミニアプリで、開発者コンソールを利用できる場合の補助手順です。旧版を削除せずに確認してください。旧版を開けない場合や元データが消えている場合は、この方法では復元できません。スマートフォン内だけのデータを、別のパソコンでスクリプトを実行して取り出すこともできません。

## よくある困りごと

| 症状 | 確認すること |
| --- | --- |
| 相手の猫が見えない | ブラウザ版では自動共有されません。Delta Chatでは同じチャットの同じアプリのメッセージを開き、送受信状況を確認します |
| Delta Chatで「ブラウザ版」と表示される | 共有APIを利用できていません。XDCをチャットから起動しているか確認し、必要に応じてDelta Chatを更新して開き直します |
| 猫が広場から消えた | 一覧の家の印を確認し、自分の猫なら「集会へ」で戻します |
| ごはんが押せない | お腹が85を超えていれば満腹です。時間を置きます |
| 集会を開けない | 前の集会の開始から約5分待ちます |
| 引き継いだ猫が「うちの子」にならない | 同じバックアップを選び、自分の猫を指定して引き継ぎます |
| ブラウザで保存されない | 保存を許可しているか、容量に余裕があるかを確認します。HTMLの場所やブラウザを変えた場合はバックアップから復元します |

## アプリの構成

XDCはZIP形式で、`index.html`、`manifest.toml`、`icon.png`を含みます。Delta Chatでは、ホストが提供する`webxdc.js`を読み込み、`sendUpdate`と`setUpdateListener`で状態を共有します。`webxdc.js`自体はXDCに同梱しません。

通常のブラウザでは共有APIの代わりにブラウザ内保存を使い、画面に「ブラウザ版」と表示します。バックアップの形式名は`nekoshu-backup`、形式番号は`1`です。
